# HyGen: Generative Map Creation for Hytale

Final project for **LMU CS 5998: Generative AI**.

HyGen is a generative AI system that creates playable terrain for *Hytale* from natural language prompts. The project utilizes a VAE, conditional diffusion, biome conditioning, and ControlNet to generate realistic and geographically consistent terrain while minimizing seams between map chunks.
